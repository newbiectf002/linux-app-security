# Repository Instructions

Always read `AGENTS.md` and `PROJECT_CONTEXT.md` before starting a new major task.

Before performing project work:

1. Read `PROJECT_CONTEXT.md`.
2. Read the approved baseline documents referenced by `PROJECT_CONTEXT.md`.
3. Treat Steps 1–4 as the current approved baseline.
4. Do not casually redefine Steps 1–4.
5. If experiments later reveal a concrete gap, document evidence first before proposing baseline changes.
6. Preserve raw experimental output.
7. Prefer reproducible experiments over theoretical claims.
8. Never classify a scanner result as a confirmed vulnerability solely because a tool reported it.
9. Preserve the distinction between raw finding, likely true positive, likely false positive, and needs manual review.
10. Do not delete original samples or findings.
11. Do not execute untrusted application binaries unless a task explicitly requires dynamic execution and the environment is appropriately isolated.
12. Keep static extraction separate from execution.
13. Prefer CLI, open-source, and offline-capable tools when later researching tools.
14. Prefer machine-readable scanner output.
15. Step 5 has not started unless `PROJECT_CONTEXT.md` says otherwise.
